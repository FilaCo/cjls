# ADR-0002: A VFS of `FileId`s and folded changes, as rust-analyzer's

Status: accepted, 2026-09-24

## Context

The editor's buffers and the disk both give file contents; the analysis needs stable, cheap file identities and only real changes.

## Decision

- `FileId` = index of the path in a `PathInterner` (`IndexSet`), for good.
- `Vfs` holds `?Rope` per `FileId` and folds changes until `takeChanges`: same text → nothing, created then deleted → nothing.
- `VfsPath.fromUri` normalizes `file:` URIs; other schemes stay virtual.
- The server applies the changes to the database right after each write.

## Consequences

- Two spellings of one path are one file.
- Snapshots resolve URIs through the shared, thread-safe interner.
- POSIX paths only (Q5).
