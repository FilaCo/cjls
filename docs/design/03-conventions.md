# Conventions

| # | Rule |
|---|---|
| C1 | No empty `public init() {}`: a type with no constructor has an implicit parameterless one, visible as the type is, across modules too. |
| C2 | One constructor → it is the primary one. Several → one is primary, the rest delegate to it with `this(...)` (`Rope(root)`, `init(text) { this(rooted(chunked(text), 0)) }`). Exception: only where that hurts readability or performance, with a comment why. |
| C3 | A field set from a parameter as is is declared in the primary constructor (`Parser(let input: Input<K>, let eof: K) {}`); other fields stay in the body, set there or by their initializers. |
| C4 | Regular parameters come before field ones (the compiler refuses the other order); reorder the API for it: `GreenNode(children, kind)`. |
| C5 | A foreign function that can block is never `@FastNative` — neither marked so, nor named like a C library function LLVM knows (`read`, `write`, `open`, `fgets`, `getchar`, …), which cjc compiles as `@FastNative` all the same (D13). While a thread blocks in a fast call the runtime cannot finish a garbage collection: the collector spins at full CPU, and every other thread stops at its next allocation. Take a sibling under another name (`readv` for `read`, as `StdinStream` does in `cjls/src/stdio.cj`), and check the call site goes through `_CJ_MCC_C2NStub` (`objdump -d`). A blocking call with the stub is harmless, an array pinned by `acquireArrayRawData` across it included. |
| C6 | A URI is a `stdx.encoding.url.URL` (`URL.parse`, `URL(scheme: …, path: …).toString()`), a path a `std.fs.Path` (`join`, `normalize`, `isAbsolute`, `parent`): no percent codec, `split("/")` or `"${dir}/${name}"` of one's own. What neither knows — a Windows drive in a `file:` URI — stays in one place (`loupe/src/vfs/path.cj`). A test needing an absolute path takes one under `getTempDirectory()`, which is absolute on every platform. |
| C7 | Tests are a pyramid: most are unit tests beside the code (`*_test.cj`), a function called directly; fewer go through `Server` on a `FakeTransport`, for what only the server does (lifecycle, dispatch, threading, push); the fewest drive the binary (`tests/e2e`, the editor smoke tests), one or two per feature, for what no unit test can see — stdio, a real client's capabilities, the pieces wired together. A case an e2e test could cover and a unit test can is a unit test: `cjpm test` runs in seconds, the e2e suite starts a process per test. |
| C8 | Where LSP meets `loupe` — `cjls.handlers` — the LSP types are a package, `import cjls.lsp_types as lsp`, and always written `lsp.Diagnostic`, `lsp.Range`; `loupe`'s are imported by name or with `*`. Each side keeps its own words (`loupe.Diagnostic` is not renamed after the protocol, A8), and neither an alias per type nor an explicit import helps: cjc takes `import a.X` next to `import b.*` exporting another `X` as ambiguous at every use. A package import brings no extensions, though: what an extension of `lsp_types` adds — `ErrorCode.SERVER_CANCELLED` (`LSPErrorCodes`), a type's `serialize` — needs its interface or type imported by name as well, and is then written bare. Tests speaking only LSP import `cjls.lsp_types.*`. |
